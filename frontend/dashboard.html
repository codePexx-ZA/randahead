What we need

  • Your income statement only (no balance sheet)
  • 3 to 5 financial years in total, one column per year (e.g. FY2022 to FY2026)
  • One file or several. A file with a single year (e.g. just FY2026) is added to your approved history. If a year is in more than one upload, the newest upload's figures are used
  • PDFs and scanned images can't be read
  • If your Excel file has several sheets, we read the first sheet with year columns, so put the income statement there
  • Line names in the first column. We match them by name, so your own layout works
  • Keep your subtotals (gross profit, net profit) so we can check the totals
